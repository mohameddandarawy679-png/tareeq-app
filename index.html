اليوم 1 من 60 - هتبقى محترف خطوة بخطوة

المرحلة 1: Python - اليوم 1 إلى 10 - لغة سهلة زي العربي

اليوم 1: أول كود ليك - يعني إيه برمجة أصلاً؟

الشرح المبسط: تخيل ان الكمبيوتر عامل زي طفل صغير، مش بيفهم غير لما تقوله اعمل كذا بالظبط. البرمجة يعني انت بتقوله يعمل إيه خطوة بخطوة. أول حاجة هنتعلمها هي print يعني اطبع.

print("اهلا بيك في Python")
print("انا هبقي محترف")

التدريب: اكتب 3 سطور: اسمك، عمرك، بلدك

الإجابة: print("محمد") / print("20") / print("مصر")

المشروع: اعمل برنامج ترحيب يسأل عن الاسم

اليوم 2: المتغيرات - صندوق بتحط فيه حاجة

الشرح المبسط: المتغير زي علبة، بتلزق عليها اسم، وتحط جواها حاجة. مثلاً علبة اسمها name جواها محمد.

name = "محمد"
age = 20
print(name, age)

التدريب: اعمل متغير لمدينتك ولهوايتك

المشروع: بطاقة تعريف كاملة ليك

اليوم 3: الإدخال input - خلي المستخدم يكلمك

الشرح المبسط: input يعني اسأل واستنى الإجابة. زي لما تسأل صاحبك اسمك إيه؟

name = input("ما اسمك؟ ")
print("اهلا " + name)

المشروع: شات بوت بسيط يسأل 5 أسئلة

اليوم 4: الأرقام والعمليات

الشرح المبسط: الكمبيوتر شاطر أوي في الحساب. + للجمع، - للطرح، * للضرب، / للقسمة.

a = 10
b = 5
print(a+b, a*b)

المشروع: آلة حاسبة تطلب رقمين وتجمعهم

اليوم 5: الشروط if - لو حصل كذا اعمل كذا

الشرح المبسط: لو الجو حر هشغل التكييف. في البرمجة نفس الفكرة.

age = 18
if age >= 18:
  print("بالغ")
else:
  print("صغير")

المشروع: برنامج درجات بيقولك تقديرك

اليوم 6: الحلقات for

الشرح المبسط: بدل ما تكتب 100 مرة، قول للكمبيوتر كرر كذا مرة.

for i in range(1,11):
  print(i)

المشروع: جدول الضرب كامل

اليوم 7: القوائم List

الشرح المبسط: القائمة زي شنطة، بتحط فيها حاجات كتير مرة واحدة.

langs = ["Python","JS","HTML"]
print(langs[0])

المشروع: قائمة مهام

اليوم 8: الدوال Function

الشرح المبسط: الدالة زي وصفة أكل، بتكتبها مرة واحدة، وتنادي عليها في أي وقت.

def hello(name):
  print("اهلا",name)
hello("محمد")

المشروع: حاسبة بالدوال
