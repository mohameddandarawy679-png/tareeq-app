اليوم 1: يعني إيه برمجة؟ وأول كود ليك

الدرس الأول - النظري: تخيل عندك روبوت صغير. الروبوت مش بيفهم غير لما تقوله اعمل إيه بالظبط. البرمجة هي انك بتدي أوامر للكمبيوتر خطوة بخطوة.

يعني إيه print؟ print يعني "اطبع" أو "قول". زي لما ماما تقولك "قول بسم الله".
print("اهلا بيك يا بطل")
print("انا هبقى محترف")
print("انا عندي 9 سنين")

المثال 1: print("انا بحب المانجا") - هيطبع انا بحب المانجا

المثال 2: print(5+5) - هيطبع 10، الكمبيوتر بيحسب كمان

المثال 3: print("يوسف", "علي", "مريم") - هيطبع 3 أسامي جنب بعض

خطوة بخطوة: 1. اكتب print 2. افتح قوس ( 3. اكتب الكلام بين " " 4. اقفل القوس ) 5. دوس Run
غلطة بيقع فيها الكل: لو نسيت " " أو القوس، الكود مش هيشتغل.
الدرس الثاني - العملي 🔥
